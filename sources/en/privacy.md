# Privacy

These watch faces collect and send **no data**.

Location, activity and health data are read on the watch, for display only, and never leave it. No account, no ads, no tracking.

The permissions asked at install time are only used for display: activity history and profile (sport gauges, heart rate zones), sensor history (Body Battery, stress), location of the last activity (sun and moon calculations).

This site is hosted by GitHub Pages. It uses no cookies and no analytics.
